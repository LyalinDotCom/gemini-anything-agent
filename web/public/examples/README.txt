Photographic 3D View sample, version 3

The input photograph is synthetic and was generated with Google's published
Gemini API CLI. The isolated reference and 4K orbit were generated inside the
managed Linux agent using the official CLI v0.4.2. Native tools created
transparent photographic textures; Blender 4.0.2 packed the self-contained
GLB and .blend scene. Fresh Blender renders verified front, left, back and right.

person-cat-views-v3 contains 32 direction-selected photographic views with a
continuous full 360-degree camera orbit in the web viewer. The Blender scene
animates the views. Unseen angles are inferred, rather than a measured scan.

The starter page links directly to /?sample3d=person-cat. Older experimental
assets remain for comparison, but only 3D View is offered for new generation.
